# BAT-CHECK Pro v2.0

**Smart Battery & Cranking Health Evaluation Check Kit** — Simulasi antarmuka alat diagnostik kelistrikan sepeda motor berbasis web.

## Fitur Utama
- **Layar OLED Virtual & Osiloskop Mini**: Menampilkan pembacaan real-time beserta animasi gelombang tegangan/arus.
- **4 Mode Uji Kelistrikan**: Open Circuit Voltage (OCV), Cranking Voltage Drop, Charging System, dan Parasitic Current Leak.
- **Auto-Scan 4 Tahap**: Menjalankan seluruh rangkaian pengujian secara otomatis dan menghitung skor kesehatan (SoH).
- **Simulator Skenario Kerusakan**: Preset 1-klik untuk demonstrasi kondisi normal, aki soak, kiprok overcharge, spul lemah, dan kebocoran arus.
- **Simulasi Struk Thermal 58mm**: Dilengkapi tombol cetak/simpan PDF, salin teks, dan riwayat diagnosa otomatis (`localStorage`).

## Teknologi
- HTML5 (Semantic + Canvas API)
- CSS3 (Responsive Grid + Print Media Query)
- Vanilla JavaScript (Web Audio API + LocalStorage)
